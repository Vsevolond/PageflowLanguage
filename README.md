# Pageflow

**Pageflow** — декларативный язык разметки документов, вдохновлённый SwiftUI. Создавайте красивые документы с помощью интуитивного синтаксиса стеков и модификаторов.

## Особенности

- 🎨 **Декларативный синтаксис** — описывайте структуру, не процесс
- 📐 **Автоматическое layout** — VStack, HStack, ZStack для любых задач
- 📝 **Встроенная типографика** — Text с полным контролем шрифтов
- 🔢 **Математические формулы** — поддержка LaTeX-style синтаксиса
- 🖼️ **Медиа-контент** — изображения и листинги кода
- 🎨 **Гибкая стилизация** — цепочка модификаторов для точной настройки
